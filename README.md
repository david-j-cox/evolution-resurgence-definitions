# Evolution Resurgence Definitions

This repository contains data and analysis related to evolution resurgence definitions.

## Setup

### Prerequisites
- Python 3.8 or higher
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/david-j-cox/evolution-resurgence-definitions.git
cd evolution-resurgence-definitions
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Project Structure

- `definitions_data.csv` - Main data file in CSV format
- `definitions_data.xlsx` - Main data file in Excel format
- `Agreement.xlsx` - Agreement data
- `Definition Criteria.docx` - Definition criteria document

- jupyter - Jupyter notebooks

## Usage

1. Set up your environment variables in a `.env` file:
```
OPENAI_API_KEY=your_openai_api_key_here
HUGGINGFACE_TOKEN=your_huggingface_token_here
```

2. Start Jupyter notebook:
```bash
jupyter notebook
```
